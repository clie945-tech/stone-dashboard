# 高雄國中題庫組卷平台

蒐集高雄市國中（以陽明國中為主）歷年的課程範圍與考題，整理成題庫，再依範圍、題型、難度自動產生**複習考卷**或**習作／學習單**（含答案卷，可直接列印或存成 PDF）。

開啟方式：直接用瀏覽器開啟 `exam/index.html`；若 repo 有開 GitHub Pages，網址為 `…/exam/`。

## 功能

| 分頁 | 說明 |
|---|---|
| 總覽 | 題數統計（科目、學期、來源學校）、最近產生的卷子、平台設定、JSON 備份／匯入 |
| 題庫 | 依科目、學期、單元、題型、難度、來源學校、關鍵字篩選；編輯、刪除、匯出 |
| 新增／匯入 | 逐題新增（即時預覽）、**貼上考卷文字批次匯入**、Excel／CSV 匯入（附範本） |
| 產生考卷／習作 | 勾選範圍、設定各題型題數與配分、難度配比、「優先／只用」某校考古題、避開常出題、選項隨機排序、亂數種子可重現 |
| 課程架構 | 依 108 課綱預設的國、英、數、自、社各學期單元，可依學校版本調整 |
| 資料蒐集 | 各學年度 × 考試別 × 科目的考古題蒐集進度表，以及資料來源與著作權注意事項 |

## 題目格式重點

- 數學式：`$x^2+1$`（KaTeX 排版）
- 填充空格：`___`
- 圖片：`![](圖片網址)`
- 批次匯入：題目之間空一行；選項寫 `(A) … (B) …`；以 `答案：`、`解析：`、`難度：`、`題型：`、`單元：`、`標籤：`、`來源：學校 學年度 考試別` 標示

## 資料儲存

資料存在瀏覽器 localStorage（每台電腦各自一份）。多位老師共用時，請用「匯出整個資料庫（JSON）」傳給對方，再「匯入」合併（重複題自動略過）。

## 注意

- 內建的「平台範例」題目是自編示範題，**不是**任何學校的真實考題，可在題庫頁以來源篩選後刪除。
- 各校考題著作權屬原命題單位，建議僅供校內教學與學生複習使用，並保留來源標示。

## 檔案

- `index.html`、`style.css`、`app.js`：平台本體（純前端，無需伺服器）
- `data/curriculum.js`：預設課程架構與題型、考試別
- `data/seed-questions.js`：範例題目
